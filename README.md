# AI For Games Project

## Description/overview
This project will be a player vs enemy game where you have enemy NPCs chasing the player. The difficulty will increase as you go through the waves and different enemies will have different abilities. The game will be made in Unity.

### AI Features To Include:
• Finite state machine - Through implementing enemies that follows and attacks the player

• Agent sensors - Enemies will sense when a player is nearby

• Pathfinding - Enemies will have the ability to move around the map and around objects to reach the player using A* pathfinding

• Behaviour trees - To control the animation for the between the different states

• Goal oriented action planning - To enable enemies to follow actions to gain a specific goal

• Steering behaviours and boids - For smooth movement with enemies
